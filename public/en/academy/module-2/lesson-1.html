How to Use the Calculator Correctly

📖 10 min read 🎓 Module 2 - Lesson 1

From Excel/paper to Smart Load Solution

Before (traditional method):

  1. Open the phone calculator
  2. Look up distance on Google Maps
  3. Add up miles manually
  4. Divide pay by miles
  5. Compare with your cost notes
  6. Decide (hoping you made no mistakes)

Now (with Smart Load Solution):

  1. Open the app
  2. Enter origin, pickup, delivery
  3. Enter pay
  4. See the result instantly
Before
Time8-12 minutes
Error margin20-30%
Now
Time30 seconds
Error margin<1%

1. Current Location (where you are right now)

📍 Current Location
┌─────────────────────────┐
│ Toledo, OH │
└─────────────────────────┘

Correct: "Toledo, OH" or "43604" (ZIP code)
Incorrect: "toledo" (missing state) or "Somewhere in Ohio"

Pro tip

The app uses your GPS if you allow it. Or enter it manually. Be specific: "Downtown Detroit" vs "Detroit Metro Area" makes a difference in miles.

2. Pickup Location (where you pick up the load)

Correct: Full address if you have it
Incorrect: Leaving it blank. If pickup = current location, enter the SAME address. The app will automatically calculate 0 deadhead miles.

3. Delivery Location (final destination)

Correct: City and state, always
Better: Full address if you know it

4. Load Payment (how much you get paid)

Special cases

If there is a separate FSC: Base rate $1,000 + FSC $200 = enter $1,200 (combined total)

If there is detention pay: Load $1,000 + Detention $50 = enter $1,050 (total you will receive)

5. Loaded Miles (optional — the app calculates this)

When to use it:

  • Leave blank (recommended): The app calculates the real route via Google Maps with truck routing
  • Enter manually: Only if the broker gave you exact miles

Tip: 99% of the time, leave it blank and let the app calculate.

6. Repositioning (optional but critical)

This is critical — do not ignore it

Scenario 1: Delivery in a premium zone (Atlanta) → Repositioning: leave empty — there's freight there, you wait in place.

Scenario 2: Delivery in a dead zone (Laredo) → Repositioning: San Antonio, TX — you need to move 280 miles.

7. Your Cost per Mile (your personal setting)

This comes from Module 1, Lesson 2. You set it ONCE in Settings and the app uses it in all calculations.

Complete calculation workflow

Real step-by-step example — situation:

  • You're at: Toledo, OH
  • Load pickup: Detroit, MI
  • Delivery: Atlanta, GA
  • Pay: $1,200
  • Your CPM: $1.05/mile
  1. Open Calculator → Home → Calculator
  2. Enter all data (all fields)
  3. Tap "CALCULATE" → the app processes in <1 second
  4. View results
MILEAGE: Deadhead 65 + Loaded 735 + Repositioning 0 = TOTAL 800 mi
FINANCES: Payment $1,200.00 − Total Cost $840.00 = Profit $360.00 (30% margin)
RATES: Apparent RPM $1.63/mi — REAL RPM $1.50/mi — Profit/Mile $0.45/mi
RECOMMENDATION: ACCEPT

Color code

The app uses colors for fast decisions:

Margin >25%, real RPM >$1.40/miAccept with confidence
Margin 15-25%, RPM near break-evenNegotiate or analyze
Margin <15%, RPM below break-evenDecline

Save to History

After calculating, tap [SAVE TO HISTORY] to:

  • Save all load details
  • Record your decision (accept/reject)
  • Build your personal database
  • Let Lex AI learn from your patterns

Compare Loads

Have 2 simultaneous load offers? Calculator → [Compare Mode]
The app shows them side-by-side with a recommendation: "Load B is 23% better"

Quick Recalculate

Broker counter-offered? In results: [Edit Payment] → New number → Recalculate
No need to re-enter everything.
